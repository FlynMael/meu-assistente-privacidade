# Política de Privacidade — Meu Assistente

Este é um bot pessoal de WhatsApp, usado apenas pelo seu dono para anotar gastos e notas.

Ele responde somente ao número do dono e ignora mensagens de qualquer outro número.
As mensagens recebidas são guardadas apenas no computador do dono e não são compartilhadas com terceiros.

Para remover dados, basta apagar o arquivo local do banco de dados.
